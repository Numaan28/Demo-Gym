🏋️ Demo Gym Website

A modern and professional gym website built using HTML, CSS, and JavaScript.
Created purely for demo and portfolio purposes, featuring a clean dark theme, smooth animations, and a fitness-focused layout.

✨ Features

Modern dark gym UI with orange accent

Smooth scroll and reveal animations

Workout programs and membership plans

Gym photo gallery with hover effects

Professional contact section with address

Personal signature footer with social links

🎯 Purpose

This project demonstrates front-end development skills, clean UI/UX design, and interactive elements suitable for a gym or fitness-related website.

🛠️ Tech Stack

HTML

CSS

JavaScript

📌 Note

This is a front-end demo project and does not include backend functionality or real form submission.
